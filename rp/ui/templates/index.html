LoRA 是什么？

LoRA 是一组轻量的训练权重。它保留基础模型，在少量参数里记录你教给模型的变化。导出的适配器需要搭配相同的基础模型使用。

当前工作流针对 CPU 上的小模型角色扮演学习。训练更大的模型或 QLoRA 需要独立的 GPU 训练后端。

角色与回复

更长的回复需要更多时间。CPU 上建议从 128–256 tokens 开始。角色设置仅保存在当前浏览器；更改角色会开始新会话。
